📋 Testing Instructions:

  1. Start your Next.js development server: npm run dev
  2. Navigate to: http://localhost:3000/auto-send
  3. Allow camera permissions when prompted
  4. Generate QR codes using the form above
  5. Scan the QR codes with your camera
  6. Verify that URLs automatically open in a new tab
  7. Test the profile picture click to navigate to profile page

Expected Behavior:

  • ✅ Camera should start automatically (with permission)
  • ✅ QR codes should be detected and scanned
  • ✅ URLs should automatically open in new tab after 1 second
  • ✅ Non-URL data should be displayed without redirect
  • ✅ Profile picture should be clickable and navigate to /profile
  • ✅ Manual start button should work if auto-start fails
